## Version 1

The current public version is version 1, the version certified by OSHWA.

2026-10-08: certified as open source hardware by OSHWA, UID
[US002865](https://certification.oshwa.org/us002865.html). See
[`docs/certification.md`](docs/certification.md).

A future enclosure concept — STEP exports and photos — is in [`BuildYourOwn/cad/encloser/`](BuildYourOwn/cad/encloser/); the editable source and print files are not in the repo yet. The current DIY build remains the laser-cut panel in [`BuildYourOwn/laser-cut/`](BuildYourOwn/laser-cut/).

The KiCad board in [`RheoBoard_PCB/`](RheoBoard_PCB/) is a separate prototype. Its silkscreen name
"Rheoboard V1" is the board's own label, not this DIY release.
