# Sensing Setup

This is the CAD design for the sensing setup. It uses a GL45 bottle and a tube. Print notes are on the [Parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-3D-print) wiki page.

`cap_non.stl` and `cap_easier_thread_fit.stl` are caps. `tube_100mm.stl` and `tube_100mm_barbed.stl` are tubes. `hose_connector_3mm_tubing.stl` is a hose connector for 3 mm tubing.
