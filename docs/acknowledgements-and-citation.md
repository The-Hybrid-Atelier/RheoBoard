# Citation and Acknowledgements

Hoang Vuong and Cesar Torres describe this routine in [RheoMap: Mapping Inks, Gels, Pastes, and Slurries within a Rheological Embedding Space using Retraction-Extrusion Pressure Sensor Vectors](https://doi.org/10.1145/3706598.3713835) (CHI 2025, Yokohama). In that work, each pulse is kept as a sensor vector so materials can be compared, watched as they change, and told apart by concentration. RheoBoard is open hardware for running the pulse and streaming the pressure trace.
