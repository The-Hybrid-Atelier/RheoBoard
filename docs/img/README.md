# Images

Photos and figures for the public pages. Component photos support the [Parts to buy](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-buy) wiki page, and the source notes for these files are kept with the wiki images. Part folders are `air-pump-4699/`, `air-valve-4663/`, `attiny1616-seesaw/`, `battery-prt-26059/`, `esp32-thing-plus/`, `l298n/`, `power-adapter-alt-1202/`, `qwiic-button/`, `qwiic-micropressure/`, `silicone-tube-4661/`, and `teaser/`. `panel/` and `portable/` hold the panel and portable figures, and `home-versions.png` is the home figure. The certification marks in this folder are `oshwa-certification-mark-US002865-wide.svg`, `oshwa-certification-mark-US002865-stacked.svg`, and `oshwa-license-facts.svg`. Vendor photos stay under their owners' terms.
