# Wiring

[Steps 02–04: Connect and check electronics](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Assembly-instructions#connect-control-boards) cover electronics and wiring checks. [Step 05: Connect tubing](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Assembly-instructions#connect-tubing) covers tubing. The Fritzing-style component picture is the main assembly visual; driver connection tables and continuity probe pairs are expandable references. The technical diagram is `BuildYourOwn/RheoBoardOTS/hardware/electronic-wiring/wiring-diagram.png`, generated by `wiring_diagram.py` in that folder. The DIY controller is an Adafruit PCA9685, product 815, at I2C `0x40`, on four header jumpers from the ESP32. The port table is in `BuildYourOwn/RheoBoardOTS/hardware/tube-wiring/`.
