# Calibration and measurement

[First REP test](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Firmware#first-rep-test) checks controller completion and a stored sample count through USB Serial Monitor. It does not display pressure values or verify pressure accuracy, and it is not a calibration. A defined pass/fail calibration is not in this guide yet.

The first mechanical assembly can continue without the [Sensing Setup](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Sensing-Setup). A sample measurement uses that setup: a GL45 bottle and a tube. The CAD is in [`Sensing Setup`](../Sensing Setup/). The probe also uses the Adafruit 4661 tube. How the sensing line reaches the bottle is not specified yet.
RheoData download, pairing, the connected indicator, and how to start and name a REP are not written yet.
