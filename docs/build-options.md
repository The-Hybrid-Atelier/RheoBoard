# Build options

The three builds are [RheoBoardOTS](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/RheoBoardOTS), the [RheoBoard v2 custom PCB](../RheoBoard_PCB/RheoBoard_v2/README.md), and [RheoPipette](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/RheoPipette).

The [Build options wiki page](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Build-options) uses these pictures from the repository.

- [Labeled RheoBoardOTS overview](../BuildYourOwn/RheoBoardOTS/images/rheoboardots-labeled-overview.png)
- [Earlier PCB v1.05 schematic and board layout](../RheoBoard_PCB/images/pcb-v105-schematic-and-board.png)
- [`rheopipette.jpg`](../BuildYourOwn/RheoPipette/rheopipette.jpg)

The [PCB index](../RheoBoard_PCB/README.md) lists the current v2 Altium design and earlier revisions. The [firmware reference](../code/firmware/README.md) covers the RheoBoardOTS DIY controller.

RheoPipette CAD is in [`RheoPipette_CAD`](../BuildYourOwn/RheoPipette/RheoPipette_CAD/). Print notes are on the [Portable parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Portable-parts-to-3D-print) wiki page.
