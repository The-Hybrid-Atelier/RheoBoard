# Parts to 3D print

Print files are on the [Parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-3D-print) wiki page. [`RheoBoardOTS_CAD`](../BuildYourOwn/RheoBoardOTS/cad/RheoBoardOTS_CAD/) is the CAD design for RheoBoardOTS: layout drawings, plates to print (`part_01_large_one_L298N.stl` and `part_01_large_two_L298N.stl`), the other parts to print, and a tray for each electronics board. [`Sensing Setup`](../Sensing Setup/) is the CAD design for the sensing setup, using a GL45 bottle and a tube. Concept visuals are in `BuildYourOwn/RheoBoardOTS/cad/concept/`. The earlier panel STEP files and the portable-holder CAD files are not in this repository.
