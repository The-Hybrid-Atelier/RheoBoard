# Build Your Own (BYO)

A DIY-friendly hardware path for RheoMap/SlipTopo: off-the-shelf modules and dev boards wired
together on breadboard/perfboard, documented with wiring diagrams, a bill of materials, and
step-by-step assembly instructions. No custom PCB or Altium required.

This is currently the **primary focus** of hardware development. The custom PCB variant lives
in [`../RheoBoard_V8_Final/`](../RheoBoard_V8_Final/) and is not being actively worked on right
now.

## Status

Not started yet — this is scaffolding only. See `docs/exec-plans/active/` for current work, and
`docs/hardware/build-your-own/` for process docs (BOM tracking notes, verification checklist,
revision history).

## Layout

- [`BOM.md`](BOM.md) — parts list: what to buy, where from, and why.
