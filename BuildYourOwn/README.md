# RheoBoardOTS - DIY

This folder is RheoBoardOTS - DIY: a flat 3D-printed panel, two air pumps, one valve, an ESP32 with BLE, a Qwiic MicroPressure sensor, and a REP (retraction-extrusion pulse).

Start on the [Main (DIY)](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Main-(DIY)) wiki page.

Design files are in `cad/`, parts and wiring notes are in `hardware/`, and photos are in `images/`.
