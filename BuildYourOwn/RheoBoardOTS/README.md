# RheoBoardOTS - DIY

This folder is RheoBoardOTS - DIY: a flat 3D-printed panel, two air pumps, one valve, an ESP32 with BLE, a Qwiic MicroPressure sensor, and a REP (retraction-extrusion pulse).

Start on the [RheoBoardOTS](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/RheoBoardOTS) wiki page.

Design files are in `cad/`. `cad/RheoBoardOTS_CAD/` is the CAD design for RheoBoardOTS, including the plates to print. The sensing setup CAD, using a GL45 bottle and a tube, is in [`Sensing Setup`](../../Sensing Setup/). Parts and wiring notes are in `hardware/`, and photos are in `images/`.
