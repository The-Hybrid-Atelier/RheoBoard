# CAD

Enclosure concept visuals, and the CAD design for RheoBoardOTS. The sensing setup CAD is in [`Sensing Setup`](../../../Sensing Setup/). Print notes are on the [Parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-3D-print) wiki page.

`RheoBoardOTS_CAD/` is the CAD design for RheoBoardOTS. The sensing setup CAD, using a GL45 bottle and a tube, is in [`Sensing Setup`](../../../Sensing Setup/). `concept/` holds enclosure concept visuals: `panel-annotated.pdf`, `assembly-open.jpg`, `encloser_pic1.jpg`, `encloser_pic2.jpg`, and `encloser_pic3.jpg`. CAD files are not in `concept/`. The portable-holder CAD files are not in this repository.
