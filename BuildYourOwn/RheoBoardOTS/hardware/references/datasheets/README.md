# Datasheets

Vendored datasheets and schematics for the RheoBoardOTS - DIY parts. The purchased-parts list is on the [Parts to buy](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-buy) wiki page.

The files are `4663_C14660_DC_6V.pdf`, `ESP32_Thing_Plus_Graphical_Datasheet.pdf`, `ESP32_Thing_Plus_Schematic.pdf`, `Honeywell_MPR_Series_Datasheet.pdf`, `Qwiic_Button_Schematic.pdf`, and `ZR370-02PM_4.5V.pdf`. These publisher documents stay under their publishers' terms.
