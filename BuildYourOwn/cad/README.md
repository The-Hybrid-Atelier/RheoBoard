# CAD

Design files for the RheoBoardOTS - DIY flat panel and sensing tube. Print notes are on the [Parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-3D-print) wiki page.

`encloser/` holds the panel. The folder name stays `encloser/`. `connector/` holds the sensing tube and small connector.
