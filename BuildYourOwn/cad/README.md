# CAD

Design files for the RheoBoardOTS - DIY flat panel and sensing tube, and the RheoBoardPipette - Portable holder. Print notes for the panel and sensing tube are on the [Parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-3D-print) wiki page. Print notes for the holder are on the [Portable parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Portable-parts-to-3D-print) wiki page.

`encloser/` holds the panel. The folder name stays `encloser/`. The files in `encloser/part/` are `base_panel.STEP`, `pump_holder.STEP`, `valve_bracket.STEP`, `enclosure_box.STEP`, and `enclosure_lid.STEP`. `connector/` holds the sensing tube and small connector. `portable_holder/` holds the portable holder.
