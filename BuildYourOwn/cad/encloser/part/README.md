# Panel print files

These STEP files are the printable pieces of the flat panel. Sizes and likely roles are on the [Parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-3D-print) wiki page.

The files are `part_01_holes_4mm.STEP`, `part_2.STEP`, `part_03.STEP`, `part_04.STEP`, and `part_05.STEP`.
