# Enclosure CAD

License: hardware CERN-OHL-W-2.0 — see [`../../../LICENSE`](../../../LICENSE).

`Concept_v2.STEP` and the files in [`part/`](part/) are STEP exports of an enclosure concept.
Photos of that concept are `encloser_pic1.jpg`, `encloser_pic2.jpg`, and `encloser_pic3.jpg`.

The editable CAD project that produced these exports is not in this repository. There is no STL
or slicer file, so these are not a print job yet. Treat the STEP files as supplementary until
that source is added. The current DIY build uses the laser-cut panel in
[`../../laser-cut/`](../../laser-cut/).
