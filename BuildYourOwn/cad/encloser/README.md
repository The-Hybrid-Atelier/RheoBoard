# 3D-printed panel

The pumps, valve, and electronics mount on a flat 3D-printed panel. The folder name stays `encloser/`. Print notes are on the [Parts to 3D print](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Parts-to-3D-print) wiki page.

`Concept_v2.STEP` is the full assembly, including the purchased components. The printable STEP files are in `part/`. `panel-annotated.pdf` is the placement photo. `encloser_pic1.jpg`, `encloser_pic2.jpg`, and `encloser_pic3.jpg` are CAD views. Print the panel in PLA on a Bambu Lab printer with the normal profile. Bambu Studio opens the STEP files directly. The editable CAD project that produced these STEP files is not in this repository yet.
