# RheoBoardPipette

This folder is RheoBoardPipette. `rheoboard-pipette.jpg` is the current unit: a Socorex pipette with the inline adapter, the Qwiic boards, and a disposable tip. Design files are in `RheoBoardPipette_CAD/`. `inline_pipette_sensor_prototype.scad` and `inline_pipette_sensor_prototype.stl` are the inline pipette adapter. `ESP32_ThingPlus_tray.stl` is the ESP32 Thing Plus tray. `MicroPressure_tray.stl` is the tray for the SparkFun Qwiic MicroPressure and the SparkFun Qwiic Button, because the boards are the same size.
