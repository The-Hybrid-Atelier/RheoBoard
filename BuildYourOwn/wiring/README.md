# Circuit / wiring diagrams

Diagrams showing how to connect the electronics for the BYO build.

_Empty — nothing wired up yet._

## Conventions

- **Prefer pictographic (breadboard-style) diagrams over pure schematics.** The audience is
  someone building this for the first time, possibly without an electronics background — a
  picture of "this wire goes from this pin to that pin" beats reading a schematic symbol.
  [Fritzing](https://fritzing.org/) is a good free tool for this (breadboard view exports
  directly to PNG/SVG).
- Export diagrams as PNG/SVG so they render inline on GitHub without extra tooling.
- If you keep an editable source file (e.g. a `.fzz` Fritzing project), commit it alongside its
  exported image, not instead of it.
- One diagram per meaningfully distinct wiring stage is fine (e.g. "sensor wiring," "power
  wiring") if a single all-in-one diagram gets too cluttered to follow.
- A real photo of the finished wiring, taken from the same angle a builder would see it, is a
  useful supplement to a diagram — doesn't replace it.
