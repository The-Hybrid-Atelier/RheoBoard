# Images

Hero photos, wiring reference shots, IDE configuration screenshots, and other builder-facing
images for the BYO track.

Modeled on [Calico](https://github.com/jsli96/calico), which keeps key images at the project
root (`teaser.png`, `control-Board.png`, `esp32-3s-ide-settings.png`, etc.) so the README renders
well on GitHub without digging into subfolders.

_Empty — add images as the build takes shape._

## Suggested files (rename to match reality once they exist)

| File | Purpose |
|---|---|
| `teaser.png` | Hero image for `README.md` and tutorial overview |
| `platform.png` | Assembled laser-cut platform |
| `wiring.png` | Finished wiring (same angle as pictographic diagram in `wiring/`) |
| `ide-settings.png` | Screenshot of correct IDE/board/port settings for firmware upload |

Step-specific photos still belong in each step's `tutorial/steps/NN-*/media/` folder — this
folder is for project-wide images referenced from `README.md`.
