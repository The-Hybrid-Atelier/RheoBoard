# FA0520E valve holder

This holder is shared by all RheoBoard PCB revisions and the RheoBoardOTS DIY build. Four low stops locate three sides of the metal valve frame. The open side faces the plastic valve head.

| File | Use |
|---|---|
| [SolidCraft project](FA0520E-valve-holder.sc) | Edit the original feature history in SolidCraft 0.30.1. |
| [STEP model](FA0520E-valve-holder.step) | Open the finished solid in SolidCraft 0.42.0 or another CAD tool. The 0.42.0 rebuild of the native project loses an edge reference in `Fillet1`. |
| [STL mesh](FA0520E-valve-holder.stl) | Print at 100% scale in millimetres, flat side down. The holder measures 18.6 × 14.1 × 4.0 mm overall. |
