# Software

RheoData application notes are shared across the DIY, PCB, and portable builds. The supplied firmware currently targets DIY seesaw/L298N hardware; see [`firmware/README.md`](../firmware/README.md) for build compatibility. Install and connect steps are on the [Code](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Code) wiki page.

The download, pairing steps, the connected indicator, and how to start and name a REP are not written yet. They will be specified later in this file and in `../firmware/README.md`.
