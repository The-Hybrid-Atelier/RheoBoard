# 2P1V_Adafruit

This folder is the ESP32 sketch. The entry point is `2P1V_Adafruit.ino`. Arduino requires the folder name to match that file. Install steps are on the [Code](https://github.com/The-Hybrid-Atelier/RheoBoard/wiki/Code) wiki page. The pin map, OSC addresses, serial commands, and REP timing are in `../README.md`.

The other files are `PneumaticSystem.h`, `PneumaticSystem.cpp`, `RheoSystem.h`, and `RheoSystem.cpp`.
